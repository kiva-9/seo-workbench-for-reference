# Google 资源发现与项目认领

项目基础资料只维护项目名称和项目域名。负责人、状态和备注按业务需要设置；Google 数据来源可以分别使用不同账号。

## 从账号到项目

1. 在“系统管理 → 谷歌账号”连接账号。授权成功后，后台开始读取 GSC 站点、GA4 媒体资源及数据流；已有账号可以点击“刷新目录”。
2. 在“系统管理 → 项目候选”查看发现的网站。所有成员都可以浏览候选，个人忽略只影响自己的列表，可在“已忽略”中恢复。
3. 点击“认领项目”，填写项目名称并核对自动带入的域名。左栏选择 GA4，右栏选择 GSC，每栏按页展示可用目录资源，域名匹配的排在前面。搜索会查找完整目录中的名称、完整资源 ID、域名及账号；可以翻页选择，已选资源在搜索和翻页后仍保留。只有全目录中唯一且完整的域名匹配项会被预选，其他资源可手动选择。
4. 确认后创建正式项目，当前登录成员成为负责人。只有一个来源时也可认领并按现有项目流程取数。多人同时认领只允许一个创建成功，其余成员会收到刷新提示。

已有对应项目时使用“关联项目”。关联要求有该项目的访问权限，负责人保持不变；默认保留已有人工来源。明确勾选替换后才将选中资源写入来源配置。

网站搜索旁的“重置”恢复当前标签的全部候选。搜索期间标签数字和列表使用同一搜索范围；切换标签会清空搜索并回到第一页。

## 人工匹配与资源范围

项目管理卡片的“资源匹配”打开同样的双栏选择器。资源来自自己管理的账号、已授权给该项目的资源，或管理员可访问的目录。候选关联可以授予项目对选中资源的使用权限；项目成员不会因此获得整个 Google 账号或凭证的管理权限。

保存的来源不会被目录刷新覆盖。“明确停用此来源”会暂停对应取数，保留项目、文章与历史成功指标。后续可重新选择已授权资源恢复。

候选识别和推荐匹配把前导 `www` 与裸域视为同一网站，其他子域仍独立。旧候选 ID 和项目引用保留；同网站已有认领时优先显示已认领入口，不自动合并或改写已有业务项目。

GSC 的域名属性和完整 URL 前缀具有不同覆盖范围；候选归组不会改写完整资源地址或扩大 Google 属性实际覆盖范围。GA4 的网站地址来自数据流配置，当前指标仍按路径统计。包含多个网站的资源需要明确确认共享范围；同一裸域的 `www` 流不额外视为其他网站。目录信息不完整时需要人工核对。

## 同步失败和账号断开

目录任务保存分页进度，并检查账号授权版本和当前操作权限。GSC 与 GA4 分别保存同步状态；分页或数据流读取失败会保留最后成功目录，在账号中心查看错误并重试。只有完整成功读取某来源后，才标记该来源中不再可访问的资源。目录同步不自动抓取业务指标。

只有连接者或管理员可以刷新、查看整个账号目录、修改账号备注或断开。断开前展示受影响项目，断开后清空对应来源并撤销该账号资源授权，项目与历史数据保留。重新连接后可从候选重新关联原项目。

## 存量与验证

迁移 `0012_google_resource_claims.sql` 新增目录、同步任务、候选、个人偏好、来源策略与项目资源授权。现有来源按人工选择迁入，不自动改绑。旧客户、行业、收费和合同列保留在数据库中，当前界面与 REST/MCP 项目资料契约不再维护或输出这些字段。

自动测试使用临时 SQLite 和模拟 Google 响应，覆盖分页、多数据流、部分失败、权限变化、并发认领与历史指标保留。浏览器验证使用隔离临时数据实例；真实 OAuth 和目录取数按对应的验收账号与范围核验。

## 读取与缓存

项目、任务、监控筛选选项和候选列表在同一浏览器页面内按当前身份缓存 30 秒，相同进行中请求共享。业务写入前后清除缓存；退出、身份变化及离开后恢复焦点时清理或重新核验。候选的“刷新”可立即重新读取。其他用户或后台任务的变更在下一次过期读取时可见，认领详情与保存版本始终实时校验。

迁移 `0016_candidate_read_projection.sql` 为目录投影增加版本记录与失效触发器。资源、网站归属和项目来源变化后，下一次候选读取重建投影；未变化时只读现有投影。重建使用事务内版本检查，避免迟到快照覆盖新状态。个人隐藏、访问权限和认领状态由查询实时合并。

`GET /api/project-candidates` 在 SQL 中执行归组、状态/网站筛选、计数和分页。`GET /api/project-candidates/:id` 的 `resources` 为每来源首批 25 条及必要推荐项，`resource_pages` 提供每来源的 `total`、`matched_count`、`recommended_id`、`page`、`page_size` 和首批 `ids`。`resources=picker` 返回选择器所需字段。

完整目录通过 `GET /api/resources/search?candidate_id=...&source=gsc|ga4&q=...&page=...&page_size=...` 分页查询（默认 25、最大 100）；使用 `project_id` 时先校验项目访问权，再限制为本人账号或已授予该项目的资源。资源选择仍以完整 ID 确认，保存时重新核验可用状态、授权和候选版本。
