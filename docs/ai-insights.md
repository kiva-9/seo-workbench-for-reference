# AI 见解

项目看板通过分类计数快速定位待优化、复盘和收录变化。结果详情左侧突出核心结论、保存事实与建议下一步，右侧是查看/检查、人工处理和可选备注；使用说明以较低视觉权重独立呈现，技术记录与完整证据默认折叠。窄屏先显示结论和建议，再显示操作，随后是证据和说明。处理备注与状态一同保存，重新生成保留人工记录；详情最多展示最近 20 条处理记录，按时间及同刻写入顺序倒序，继续遵守项目权限。

侧边栏的 `AI Features` 位于工作空间之后、系统管理之前，包含「AI 见解」「Agent 接入」「AI 功能配置」。AI 见解的跨项目主看板和项目看板都使用「行业资讯」「文章监控」「收录监控」三个 Tab，默认打开行业资讯，页首可直接切换。项目选择器支持名称搜索和键盘选择，AI 功能配置中的项目选择也可搜索。服务端按当前权限查询当前 Tab 的卡片，其他 Tab 只查询数量，运行记录与费用展开后读取；初次加载、切换和翻页不传输隐藏模块的卡片。每个 Tab 的筛选和分页保存在 URL，详情返回原来的列表和滚动位置。项目切换保留当前模块和筛选，页码重置。资讯按发布日期分组，突出标题、摘要、来源与项目关联。资讯与文章列表优先展示通过证据校验的 AI 摘要，让多月分析在列表直接可读；模型不可用时保留规则事实，详情同时可核查原始事实和完整证据。看板、证据详情和配置页都有独立加载态；Tab 切换只更新工具栏与当前面板，保留页面标题。后台状态使用有界的单任务轮询。

## 本地演示

使用 Node 24 与锁文件安装依赖，在仓库目录运行：

```bash
npm ci
node scripts/ai-insights-demo.cjs
```

脚本创建全新的系统临时目录，设置 `SPM_DATA_DIR`，写入合成案例，然后通过 `npm run dev` 启动，默认地址为 `http://127.0.0.1:8588/#/ai-insights`。端口占用时可用 `PORT=8589 node scripts/ai-insights-demo.cjs`。`--seed-only` 仅建立并输出新的临时目录。脚本不读取项目 `data/` 或 `.env`，也不访问 Google、新闻站点或模型供应商。演示适配器只允许使用带演示标记的临时目录，卡片和页面明确标注合成数据。

默认演示账号是成员，用于验证项目隔离。需要查看管理员模型页面时，在另一端口运行 `PORT=8590 node scripts/ai-insights-demo.cjs --admin`；它创建另一份全新的合成库，管理员能看到所有合成项目。仅用虚构密钥测试保存与清除，演示模式不会发送真实请求。

演示路径：

1. 从侧边栏进入主看板，查看两个授权项目的三类结果；第三个合成项目不在当前用户权限内。
2. 展开文章栏的「筛选」，选择「优先优化」，下钻项目并打开证据；检查两个完整月、真实零与未知的区别，标记「有用」。返回后保留筛选和位置。
3. 打开资讯，查看项目匹配依据、来源关系和选题线索；必要时展开完整证据查看抓取与日期口径；在「AI 功能配置 → 项目、RSS 与关键词」中选择项目，维护关注词和已批准来源。
4. 打开收录变化，核对前后快照与 Google 判定；失败卡片仍展示最后有效状态。点击「检查此 URL」，等待最终状态并检查当天快照复用提示。
5. 在项目小看板分别运行三个模块，展开「运行记录与来源状态」查看计数、限制和费用状态，再返回主看板。读取页面和轮询本身不会执行任务。

退出开发服务后，合成目录可按脚本输出的位置自行删除。不要把临时目录路径改成实际业务库。

## 三类结果

文章表现只对具备 URL 级指标的站内文章判断。默认观察最近十二个完整月，可配置三至二十四个月，并额外读取上年同期月份。保留最近两个完整月对照，同时提供连续月变化、前后完整季度、同期对比和同项目成熟可比文章参考。季度点击另算日均值，CTR 使用总点击除总展示，排名按展示加权；不跨缺月连接趋势，不用同比单独证明季节性。长期完整证据也可形成优化或复盘候选，继续使用项目暂定门槛和成熟度、新鲜度条件。缺月、覆盖不足、最新同步失败、URL/修订不一致不能形成强分类。GSC 和 GA4 分别展示，零基期只计算绝对变化，当月字段另列。暂定规则包括成熟度、最低样本、点击变化、CTR 与排名区间，均可在项目设置修改或关闭；原有达标口径不变。

文章模型接收确定性生成的定性事实：指标方向、零基期、可比性、规则分类与限制。文章标题与登记关键词作为主题背景，登记关键词不代表实际搜索查询；其中的型号/版本数字在模型投影中屏蔽，不能给指标数值作证，原标题及关键词仍在原登记证据中保留。多月方向、持续变化、季度、同期与项目参考由规则计算后生成定性事实。季度排名按有展示月份加权，零展示月份不产生权重；有展示但排名缺失时仍保持未知。模型优先解释短期与较长周期的一致或分歧，核查建议对应具体变化或限制；上线前和上线当月的覆盖不足不会被描述为可补抓的数据缺口，GSC 点击与 GA4 全渠道浏览不作为因果证明。原始数值、百分比、具体日期、规则阈值和文章 URL 保留在卡片的完整证据中，不需要模型重复计算或抄写。模型引用的定性证据在卡片内保存到原快照的引用，后台请求只携带定性投影与必要项目背景。投影版本进入任务输入，旧格式计划不能按新格式继续调用；旧日任务取消后，当天的调度去重记录仍保留，需要手动更新或显式重试，次日才按计划重新调度。已有完整可比数据但样本较低时，建议继续积累样本；缺失或不可比时才要求补齐或核查基线。

资讯可配置直接 RSS/Atom 或关键词新闻搜索。搜索查询由服务端固定生成 Google News 的公共 RSS 地址，聚合来源按 feed 声明的原发布机构归类；其材料仅作发现线索，需要核查原文。仍只读取明确批准来源的标题、允许保存的摘要与原文链接。多个来源使用三路有限并发，故障相互独立；最多三百个候选按来源均衡保留，超出范围显示延后计数，原抓取记录保留。关键词、排除词和时间窗作确定性筛选；英文词或短语按单词边界匹配，中文保留包含匹配，PC 不会因 HPC 或 RPC 命中；官方一手来源优先作为重复报道的代表，材料不足或日期待核查的内容只作观察记录。GUID、标准 URL 与可靠的相同摘要用于强去重，标题相近仅标记「可能相关」。精选先保留各个材料充分且日期有效来源的代表，再按声明来源分级、关注词和新鲜度补充；同一发布机构的展示上限可配置，避免高频搜索或多个 feed 占满结果，来源覆盖不会把待核查材料提到有效资讯前。每条入选资讯的解读还收到同关注方向的其他事件、发布时间和来源覆盖，关联报道作为可引用证据，模型使用本次请求的简短编号，保存时精确还原原证据 ID，比较材料的一致、分歧和项目适用条件；关注词重叠只表示可能相关，不强行合并或宣布行业趋势。配置页提供已验证可读取的 DATRON、Autodesk、NVIDIA 和 Windows feed 来源库，添加后仍明确维护使用批准。来源类型由用户核实，不代表真实性认证；当前模块不把单篇报道称为趋势，不推断搜索量，也不补抓网页全文。

收录检查使用 Google URL Inspection，只检查本项目有效的站内文章，复用现有 Google 授权和项目资源认领。执行成功、失败与业务状态分开；无前序成功快照不能称为「新收录」，失败不能称为掉收录。URL、property 或修订变化会要求复核。单条与批量检查在同一上海业务日复用相同检查口径的项目内快照；显式重试绕过缓存，但仍消耗共享预算。不同项目共用 property 配额，缓存不跨项目泄漏证据。

## AI 功能配置

侧边栏「AI 功能配置」（`#/ai-settings`，原模型地址仍可使用）集中维护模型与项目功能。管理员的「模型与调用开关」可管理最多二十个模型条目，各自保存显示名称、Base URL、模型 ID、加密密钥和可选价格；明确选择主模型和不同的 fallback。项目成员在「项目、RSS 与关键词」中维护有权限项目的背景、资讯、文章规则和调用设置。模型与外部开关写入仍只允许管理员。

外部调用开关使用 `GET/PUT /api/admin/ai-runtime`，保存后立即成为模型、资讯和收录任务的外部请求开关。关闭保留已保存事实，不触发抓取。开关版本加入请求与最终写入守卫，改变开关会取消旧配置的排队/迟到任务；已经发出的模型请求仍保留账本。部署暂停强制关闭外部调用，保存的开关不能绕过暂停。自动日调度仍独立配置。

`GET/PUT /api/admin/ai-model` 返回无密钥的模型列表和主备选择，支持旧单模型写法。Base URL 为公共 HTTPS 基础路径，请求追加 `/chat/completions`。保存不测试连接、不访问模型列表或产生付费请求。主模型明确拒绝或已完成响应未通过校验时，最多尝试一次备用模型；网络结果、费用或授权不确定时不会切换重发。两次请求分别预留和记账，结果保留实际模型、用量和 fallback 状态，切换模型不会重授项目额度。

阶跃官方 `/v1` 与 `/step_plan/v1` 使用 `max_tokens`；`step-3.7-flash` 使用 `reasoning_effort: low` 与[严格 JSON Schema](https://platform.stepfun.com/docs/zh/guides/developer/json-mode)。其他兼容端点使用 `max_completion_tokens` 和 JSON object。供应商格式以各模型条目生成，所有结果继续经过本地结构、引用与事实校验。

API Key 使用 AES-256-GCM 加密后保存，不回显、不放入任务输入或配置审计；留空保留原密钥，勾选清除会停用条目；清除主模型时也停用全局模型配置，清除备用时解除备用选择。变更供应商地址时必须重新填写或清除密钥。配置有乐观版本控制和管理员操作记录，保存时再次在事务中检查管理员身份；撤销管理员角色后不能继续读取或保存。保存版本会进入任务守卫，旧配置队列或迟到模型结果不能继续提交。

首次保存密钥时在 `SPM_DATA_DIR/.ai-model-key` 生成权限 0600 的服务器加密文件。应用的数据库一致性备份同时保存此文件；迁移到另一台机器或恢复完整备份时必须带上与密文匹配的文件。文件丢失时不会尝试猜测密钥；管理员可恢复备份中的文件或重新填写供应商 API Key。不要打印、提交或通过聊天传递该文件。旧环境变量在没有网页保存配置时作为默认；一旦保存，以管理员设置为准（包括停用和清除），不会悄悄回退到旧环境密钥。

## 配置与授权

环境变量见 `.env.example`：

| 配置 | 默认 | 用途 |
| --- | --- | --- |
| `AI_INSIGHTS_ENABLED` | `true` | 模块 API 与独立后台消费器 |
| `AI_EXTERNAL_ENABLED` | `false` | 允许外部资讯、Google 和模型请求 |
| `AI_SCHEDULE_ENABLED` | `false` | 允许每日入队器 |
| `AI_MODEL_NAME` / `AI_MODEL_KEY` | 空 | 未保存网页配置时的服务端默认模型与凭证 |
| `AI_MODEL_ENDPOINT` | OpenAI Chat Completions HTTPS 地址 | 管理员配置前的默认端点，项目文本不能覆盖 |
| `AI_MODEL_INPUT_RATE` / `AI_MODEL_OUTPUT_RATE` | 未配置 | 每百万 token 的美元价格；费用模式必须配置 |
| `AI_MODEL_CALL_CEILING` | `0` | 服务端单次费用上限；费用模式必须显式设正值 |
| `AI_DEMO_MODE` | `false` | 仅限上述新建临时目录的固定演示适配器 |

实际模型接入需确认供应商、数据使用和费用授权。项目还需开启模型、确认发送项目背景与必要证据，并选择调用限制模式及输出 token 上限。默认“次数与费用”同时校验单次预留费用、每日费用及管理员价格/单次上限；价格或请求费用上界无效时不发送请求。明确选择“仅限制调用次数”可暂不填写价格和金额上限，仍逐次计数；无价格时实际费用为 `null`，不代表免费，也不承诺金额上限。「测试不限额」是明确选择的第三种模式，不限制次数、金额或项目模型分钟上限，仍逐次记录请求/token/实际模型。未知费用与不确定请求继续保留；不确定请求仍暂停后续调用，不自动启用日调度。仅配置密钥不会自动授权外发，密钥不会返回浏览器或写入见解。未配置模型时，确定性分类、证据和人工处理仍可用。

项目设置包含行业、产品、目标市场/语言、推广重点、关注/排除词、最多二十个已批准来源、规则、配额和每日运行小时。背景仅保存解释必需的信息。来源可标记官方一手、媒体转载或尚未核实，也可填写统一发布机构。资讯最少摘要字数和同发布方上限属于可配置、可测试的暂定规则。

owner、仍在册文案师和 admin 沿用现有业务访问规则。所有读取、聚合、入队、执行、反馈与最终事务写入均再次校验当前服务端权限。撤权、项目 Google 绑定、配置版本或文章输入变化会取消迟到结果。Google 授权及资源可见性也由收录模块单独守卫。

## 任务、预算与恢复

任务存在 SQLite 中，独立消费器不依赖 `MCP_BACKGROUND_ENABLED`。每日执行采用 `Asia/Shanghai`，时间戳存 UTC；项目启用每日任务和服务端日调度开关缺一不可。同项目、模块、输入、模型/提示版本与业务窗口生成幂等键，重复提交返回同一任务。读取不会推动执行。

外部请求前原子预留配额；网络失败同样消耗次数。模型预留费用与已知费用取较大值用于预算判断。未知费用保留 `null` 和预留额，不当作零。模型调用结果不确定后暂停该项目后续模型请求，需要核查供应商账单后另行处理；不自动清零，不自动重发。仅限制次数的调用预留金额为 0，但实际费用无价格时仍为 `null`。当天存在没有预留额的未知费用时，切回费用模式会阻止调用，避免把未知花费当作零；切换模式也不重置请求次数。预算约束不依赖模型服务是否支持幂等头。

运行租约过期时，尚未开始外部请求的任务可恢复为排队；已经开始外部请求的任务标记 `uncertain` 并保留预算。失败、部分完成或取消的任务可显式关联原任务重试，结果或费用不确定的任务不提供自动重试。模型不可用、输出校验失败或预算不足时保留规则事实和限制，不伪装成 AI 成功。数字或链接拒绝仅记录本地生成的字段名及原因（未知数字、与已知数字相反符号、未支持链接），不保存被拒正文、数字值或推理内容；符号诊断不表示已确认模型只犯了格式错误。

数字校验保留正负方向。「指标 + 下降/减少 + 幅度」须按同一指标和单位匹配确定性比较证据中的负变化；无明确指标的裸幅度、其他指标或标题中的负数不能代替该变化。「下降至 + 终值」按原值检查，不取绝对值放行。带「月」的月份区间必须匹配已保存比较期的年份和有序端点，不能借用当月观察或指标数字。以上只是数字展示兼容，不能替代对因果、项目相关性及措辞强度的人工评审。

资讯安全层限制 DNS/IP、重定向、端口、超时、响应大小和压缩方式，拒绝本地、私网、元数据地址及 DTD。只允许人工批准来源，模型不能访问 URL 或调用工具。摘要、标题与项目背景均按不可信数据传入解释器。

本期未启用自动删除历史快照和运行记录。列表有界、资讯候选有上限不等于数据库保留期限；持续启用日任务前，应按项目容量另行确定保留与清理策略。项目删除遵循外键清理；不要自行编写线上清理 SQL。

## 迁移、接口与验证

收录详情先呈现官方事实，AI 仅在独立的补充解读中展示。`口径变化需复核` 是工作台的比较提示，不能解释为 Google 审核或审批状态。收录模型只接收 `indexing-facts-v1` 的可追溯定性事实，具体 URL、时间、verdict 与比较身份留在原始快照；旧输入计划在外发前取消。输出中的审核/审批状态、已完成提交或所有检查项达标说法被拒绝，已保存的旧解读也在授权读取时过滤，保留官方结果和历史库记录。这是针对已知语义混淆的约束，仍需要业务质量审阅。

新增迁移 `0017_ai_insights.sql`、`0018_ai_model_configuration.sql` 与 `0019_ai_model_profiles.sql`，由现有启动迁移器增量应用，不修改已发布迁移。升级自动测试使用合成旧库，覆盖旧业务库升级及 0018 单模型配置无损升级，保留原密文、主模型选择、项目记录和账本、重复迁移无新增写入、`integrity_check` 和 `foreign_key_check`。发布前还会使用部署暂停的隔离副本演练。需要暂停模块时关闭模块和外部调用开关，保留新表及账本，不删除预算状态。

模块协议、文件所有权、API 与错误格式见 [AI 见解接口](ai-insights-contract.md)。新增 API 使用统一错误 `{error,code}`。设置写入使用版本冲突 409；未授权返回 403，不返回该项目结果。

内部仓库配套覆盖迁移与三个模块的 `node:test` 自动化测试（合成输入 + mock 外部调用）；本参考版未随附测试套件。

自动测试与上述演示使用可重复的合成输入及 mock，不能替代已批准供应商的真实接口验收。真实接口验证的版本、样本范围与结果以对应的验收记录为准。固定样本重复测试与留出样本用于检查规则稳定性；真实模型的人工质量评审与同案例人工/辅助总耗时比较是独立验收项，不能从通过单元测试或少量接口调用推导这些结果。
