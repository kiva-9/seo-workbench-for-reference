# MCP 接入与能力边界

MCP 与网页/API 共用同一 Node + SQLite 应用、权限和业务服务。经反向代理部署时，MCP 地址为 `https://<你的域名>/mcp`。

## 连接与认证

- 使用无状态 Streamable HTTP，`POST /mcp` 携带 `Authorization: Bearer <PAT>`。GET 返回 405，不开放 SSE 监听、resources、prompts、任意 SQL 或任意 HTTP 工具。
- 在“Agent 接入 → MCP 管理”生成、重置或撤销个人 Token，明文只在生成或重置时显示。退出网页不会撤销 Token；重置或撤销后旧 Token 立即失效。
- 每账号最多 5 个同时有效的永久 PAT，创建时必填 1–80 字的名称。满额须先撤销一个；每个 Token 独立重置/撤销，其他客户端凭证保持有效。列表显示名称、非秘密标识、创建/最近使用时间和状态，不返回完整值或哈希。
- 已撤销的凭证保留在列表中，不占有效名额，不能重置恢复。
- 网页、普通 API 和 OAuth 回调通过 Cloudflare Access；MCP 及其导出路径使用独立 PAT，不回落本机默认账号。
- Token 绑定账号，按每次调用时的账号角色、项目名单和实时权限筛选。新增项目、移出成员、角色变化都按当前权限处理。

## 工具与开放范围

工具注册、严格输入与公开输出定义以 [registry](../src/mcp/registry.js)、[读取服务](../src/services/mcp-read.js)、[写入服务](../src/services/mcp-write.js)、[长任务服务](../src/services/mcp-operations.js)和 [输出契约](../src/contracts/mcp-output.js) 为准。

| 能力 | 范围 |
| --- | --- |
| 20 项读取与分析 | 项目上下文、站内/外链文章与指标、平台、身份、任务、链接、名单、数据源、规则、健康、报告、操作状态与结果 |
| 19 项普通写入与导入 | 任务/链接/文章登记与修改、导入、已有成员指派、URL/启停/平台/排序、数据源配置、项目创建/修改及文章删除 |
| 9 项计划与长任务 | 导入预检、同步计划、有限批量预览、同步启动、取消/重试、标题抓取、CSV/TSV/XLSX 导出及管理员用户查询 |

20 / 19 / 9 为服务分组，不代表发布阶段分别开放这些数量。部分管理工具另有 Admin 检查。

MCP 页面通过登录账号读取 `GET /api/mcp/tools` 的完整目录，无需先创建 PAT。名称、标题、用途说明和限制来自 MCP 协议共用的服务端注册表；目录不分页，并显示环境开关、发布阶段、后台及管理员限制。阅读或搜索目录不执行工具，也不启动 Google 抓取或后台任务。

工具使用指南按项目、表现分析、文章、任务、资料链接、账号/成员/配置、同步/导出 7 个工作目的分组。每个工具说明适用场景与结果，并提供可复制到 AI 客户端的自然语言示例。分组导航、需求搜索、操作类型/可用状态筛选及展开/收起支持逐组阅读；全部注册工具都进入目录，前端不维护独立清单。说明与示例在 [服务端使用指南](../src/mcp/tool-guides.js) 维护，用途说明同时用于 MCP 协议目录。

| 开关 | 应用默认 | 行为 |
| --- | --- | --- |
| `MCP_ENABLED` | `true` | `false` 关闭 MCP 入口 |
| `MCP_PHASE` | `1` | `1` / `2` / `3` 按工具阶段开放；以注册表过滤为准 |
| `MCP_BACKGROUND_ENABLED` | `false` | 开启同步启动、恢复、标题和导出启动工具及后台执行 |

运行环境可显式覆盖默认值；连接到某环境时通过实际工具目录核对，不从应用默认推断部署配置。

不注册新增/移除项目成员、项目所有权转移、整个项目删除和账号角色修改工具，不提供 Google OAuth 凭证管理或通用数据库操作。普通业务写入直接执行已有权限与版本规则，预检/预览是可选辅助。

## 业务规则与结果

- 写入共享实体/集合修订、CAS、幂等回执与原子审计。相同键原样重试读取原结果；同键不同输入拒绝。冲突先重新读取，不自动覆盖更新后的记录。
- 指派使用已有项目名单，历史署名不恢复访问权。权限变化也影响后台单元和导出下载。
- 未知值保留 `null`，与真实零值区分；旧配置、最近失败和最后成功事实分别表达。读取和轮询不触发 Google 抓取或推进后台任务。
- 长任务保存逐项输入、租约和检查点；取消保留已提交结果。每个单元验证 PAT、权限、配置及租约，旧执行者不能继续写入。
- 同步、标题和导出由后台推进，通过 `get_operation_status` 和 `get_operation_result` 读取终态及逐项结果。
- `GET /mcp/exports/:operation_id` 验证 PAT、账号、实时项目权限和产物有效期。下载 URL 不含 Token；CSV/TSV/XLSX 与结构化结果受文件、行数、存储和响应预算限制。
- 每账号交互并发、输入/响应、SQL、数据范围、外部请求和标题抓取安全边界由服务端执行。
